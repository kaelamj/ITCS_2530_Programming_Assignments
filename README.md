# ITCS 2530 - C++ Programming Assignments

**Name:** Kaela Jusi

**Course:** ITCS 2530

**Description:** 

This repository contains my reading tracker program for ITCS 2530. The program allows users to log their reading sessions, track their progress through a book, and calculate their average reading speed and estimated remaining reading time.

In the program's menu, users can:
- Add a book by entering its title and total number of pages.
- Log multiple reading sessions by entering the starting page, ending page, and time spent reading.
- Calculate the percentage of the book completed, average reading speed, and estimated remaining reading time. 
- View a summary of their reading progress across all logged sessions.
- Save a copy of the summary to a report.txt file.
